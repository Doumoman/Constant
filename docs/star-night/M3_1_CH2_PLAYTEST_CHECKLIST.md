# 《별을 물어오는 밤》 M3-1 CH2 플레이테스트 체크리스트

## 세션 절차

1. `Assets/Scenes/StarNight/StarNight_MagpieBridge.unity`를 연다.
2. 공략 설명 없이 한 번 플레이한다.
3. 선택한 Route 두 개, 옛 다리 수습 여부, 해치 선택, 별사다리 진입 여부를 기록한다.
4. 종료 뒤 Unity Console의 `[M2 Playtest]` 한 줄을 함께 보존한다.

## 종료 질문

1. 현재 목표가 다리 전체 수리가 아니라 별문에 연결할 닻 2개였다고 설명할 수 있는가?
2. 새 닻, 폭풍탑, 옛 물류 다리의 안전·위험·속도 차이를 구분했는가?
3. 해치 사건이 닻 기여와 별개의 필수 선택임을 이해했는가?
4. 옛 닻을 전용했을 때 다음 챕터 물류가 줄어드는 이유를 설명할 수 있는가?
5. `2/2`와 손잡이 가동이 다른 단계임을 이해했는가?
6. 별사다리가 즉시 출항 대신 선택하는 위험한 잔류라고 느꼈는가?
7. 세 번째 방울에서 마루가 다리 전체를 흔들며 플레이어를 직접 쫓는다고 이해했는가?

## 기술 확인

- A+B, A+C, B+C 조합이 모두 GateReady에 도달한다.
- 해치 선택만으로 GateContribution이 증가하지 않는다.
- 해치 미해결 상태에서는 GateActive 뒤에도 출항할 수 없다.
- 별사다리 봉인은 GateActive만으로 열리지 않고 입구 선택 뒤 열린다.
- 별사다리 진입 전에 끊어지지 않는 매듭을 획득할 수 없다.
- Route C 대체 닻은 GateReady 전에만 설치할 수 있다.
- Bell 2에서 마루는 플레이어보다 짐과 주민을 먼저 고른다.
- 출항 기록에 CH2 Route 조합, GateActive, BellPhase가 남는다.
