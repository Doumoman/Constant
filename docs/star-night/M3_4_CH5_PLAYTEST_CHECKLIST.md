# 《별을 물어오는 밤》 M3-4 CH5 플레이테스트 체크리스트

## 세션 절차

1. `Assets/Scenes/StarNight/StarNight_SleepingSunGarden.unity`를 연다.
2. 공략 설명 없이 한 번 플레이한다.
3. 선택한 Route 두 개, 해오름 처리, 멈춘 방 진입, 정원 열과 최종 방울을 기록한다.
4. 종료 뒤 Unity Console의 `[M2 Playtest]` 계측 한 줄을 함께 보존한다.

## 종료 질문

1. 현재 목표가 별길 나무에 빛 세 번이 아니라 길꽃 빛 두 개였다고 설명할 수 있는가?
2. 저장 햇빛, 온실 꼭대기, 해오름 기상의 안전·위험·속도 차이를 구분했는가?
3. 해오름을 자연 기상시키는 것과 Route C 강제 기상의 결과 차이를 이해했는가?
4. 정원 열 70의 과열과 95의 화재, 희귀 씨앗 수습 조건을 발견했는가?
5. 마루의 “모두 집으로. 아무도 잃지 않게.”를 보호와 감금 중 어떻게 해석했는가?
6. `2/2`와 손잡이 가동이 다른 단계임을 이해했는가?
7. 멈춘 방이 즉시 출항 대신 선택하는 위험한 잔류라고 느꼈는가?
8. 최초 명령 원본과 최종전 빛 보조가 선택 보상임을 이해했는가?
9. 세 번째 방울에서 모든 광원이 길과 위험을 함께 드러내는 이유를 설명할 수 있는가?

## 기술 확인

- A+B, A+C, B+C 조합이 모두 GateReady에 도달한다.
- Route A는 서로 다른 지정 저장원 세 곳을 수집해야 완료된다.
- Route B는 온실 꼭대기 반사 두 번째 상호작용에서만 완료된다.
- Route B 두 번째 반사에서 덩굴이 과성장하고 빛나방이 깨어나며 귀환 발판 장벽이 실제로 켜진다.
- Route C는 저장 햇빛을 소비한 강제 기상에서만 완료된다.
- 자연 기상만으로 Route C와 GateContribution이 증가하지 않는다.
- GateReady에서는 출항과 멈춘 방이 열리지 않는다.
- 길꽃 두 개를 장착한 뒤 손잡이를 다시 당겨야 GateActive가 된다.
- 멈춘 방은 GateActive 뒤에도 입구를 직접 선택해야 통과된다.
- 주머니 해님과 최초 명령 원본은 멈춘 방 진입 전에는 획득할 수 없다.
- Bell 2에서 마루는 빛나는 씨앗과 깨어난 생명체를 우선 추적한다.
- 출항 기록에 CH5 Route 조합, GateActive, BellPhase와 북극성 관측소 전환이 남는다.
