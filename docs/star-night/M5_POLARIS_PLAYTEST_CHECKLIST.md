# M5 북극성 관측소 플레이테스트 체크리스트

## 목적

북극성 최종전이 앞선 다섯 챕터의 선택을 다시 읽게 만들고,
중심별 추격과 네 엔딩이 설명이 아니라 실제 행동으로 구분되는지 확인한다.

## 공통 준비

- 프롤로그부터 CH5까지 진행하거나 관측소 씬을 직접 재생한다.
- 정상 런에서는 여행 티켓에 별문 도장 `5/5`가 표시되는지 확인한다.
- `T`로 티켓을 열어 플레이어와 마루가 북극성 정거장에 도착했는지 확인한다.

## 핵심 진행

- [ ] 기록 회랑에서 CH1~CH5의 대표 행동을 한 번씩 확인할 수 있다.
- [ ] 같은 기록을 다시 읽어도 진행 수가 중복 증가하지 않는다.
- [ ] 기록 5/5 전에는 닫힌 관측실의 진실 확인이 거부된다.
- [ ] 진실 확인 뒤 라니의 평가와 세 문장 반박이 읽힌다.
- [ ] 중심별 카운트다운과 마루의 역이용 도구가 HUD에 표시된다.
- [ ] 절구 → 붉은 실 → 구름병 → 별 우편 도장 → 햇빛 씨앗 순서만 통과한다.
- [ ] 잘못된 순서의 도구를 써도 복구 단계가 증가하지 않는다.
- [ ] 다섯 도구 복구 뒤 카운트다운이 멈추고 네 갈래 선택이 가능하다.

## 엔딩 확인

각 엔딩은 별도 런 또는 테스트용 직접 진입으로 확인한다.

- [ ] `길을 끊는 사람`: `ENDING_PATHCUTTER`, `JourneyComplete`
- [ ] `새 목줄`: `ENDING_NEWLEASH`, `JourneyComplete`
- [ ] `닫힌 우주`: 직접 선택 또는 시간 초과, `ENDING_CLOSEDUNIVERSE`
- [ ] `별길`: 네 조건 충족 뒤 `ENDING_STARROAD`, `POLARIS_RANI_DELIVERED`,
      `POLARIS_MARU_RELEASED`, 마지막 행동 `RaniCommandWithdrawn`

## 별길 조건 매트릭스

| 묶음 | 충족 예 | 실패 예 |
|---|---|---|
| 기억 | 파괴되지 않은 마지막 편지 | 편지 파괴 후 대체 기억도 없음 |
| 대체 기억 | 명령 전체 맥락 + 보존된 동생 화분 | 둘 중 하나만 발견 |
| 연결 | 붉은 실 + 마루 최초 명령 | 최초 명령 미확인 |
| 배송 | 별 우편 도장 + 라니 배송 가능 + 북극성 항로 | 항로 미등록 |
| 빛 | CH5 멈춘 방의 최종 빛 보조 | 최종 빛 미획득 |

- [ ] 네 묶음 중 하나라도 없으면 별길 상호작용이 거부되고 부족한 다이아가 `◇`로 보인다.
- [ ] 편지를 파괴했어도 대체 기억 두 조건을 모두 채우면 기억 다이아가 `◆`로 바뀐다.

## CH5 상속과 시간

- [ ] 해오름 자연 기상, 정원 복구, 최종 빛, 안정 별길은 제한 시간을 늘린다.
- [ ] 강제 기상, 방치한 화재, 과성장·소실 별길은 제한 시간을 줄인다.
- [ ] 시간 초과 시 마루가 중심별에 먼저 도달하고 닫힌 우주로 종료된다.
- [ ] CH5 환경 결과가 관측소의 광원, 화재 흔적, 화분, 항로 형태로 보인다.

## 가독성·조작·안정성

- [ ] 현재 목표, 남은 시간, 다음 필수 도구, 별길 조건을 한 화면에서 읽을 수 있다.
- [ ] 23구역 이동 중 낙하 복구와 체크포인트 6개가 정상 작동한다.
- [ ] 네 엔딩 선택대의 색과 제목이 멀리서도 구분된다.
- [ ] 최종 엔딩 패널이 일반 챕터 휴식 요약 없이 바로 열린다.
- [ ] 콘솔 오류, 누락 스크립트, 깨진 프리팹이 없다.
