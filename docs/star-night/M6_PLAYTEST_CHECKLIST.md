# 《별을 물어오는 밤》 M6 밸런스 플레이테스트 체크리스트

## 목적

자동 테스트로 확인할 수 없는 실제 플레이시간, Route 선택 분포,
유혹 구역의 매력, 방울 압박의 이해도, 일반/별길 엔딩의 정보량 차이를
10개 전체 런으로 측정한다.

## 표본 구성

- 일반 엔딩 전체 런 `5세션`
- 별길 엔딩 전체 런 `5세션`
- 같은 사람이 반복할 경우 학습 순서를 기록한다.
- 관측소 직접 실행은 디버그 런으로 제외되므로 반드시 프롤로그 빌드부터 시작한다.
- 일반 그룹은 공략 설명 없이 진행한다.
- 별길 그룹은 시작 전에 필요한 선행 챕터 조건만 안내하고,
  최종 선택과 엔딩 설명은 미리 알려 주지 않는다.

## 시작 전 기술 게이트

- [ ] `Tools > Star Night > Run M6 Balance & Regression Audit`가 `25/25 PASS`다.
- [ ] 전체 EditMode 테스트가 `158/158`이다.
- [ ] 빌드 순서가 `Prologue → CH1 → CH2 → CH3 → CH4 → CH5 → Polaris`다.
- [ ] Console 오류 0, 새 경고 0, 7개 씬 누락 스크립트 0이다.
- [ ] 정식 표본을 새로 시작하는 경우에만 `Clear M6 Playtest Aggregate`로 이전 표본을 지운다.

## 목표 구간

| 측정값 | 목표 | 중단·재검토 기준 |
|---|---:|---|
| 일반 엔딩 전체 시간 | 45~60분 | 5세션 중앙값이 범위 밖 |
| 별길 엔딩 전체 시간 | 60~80분 | 5세션 중앙값이 범위 밖 |
| 유혹 진입률 | 55~70% | 50개 기회 중 28~35회 밖 |
| 개별 Route 선택률 | 10% 이상 | 한 챕터 20개 장착 중 2회 미만 |
| 프롤로그 | 5~7분 | 핵심 원인을 놓치거나 범위 반복 이탈 |
| CH1·CH2·CH3·CH5 | 각 8~10분 | 특정 경로 때문에 반복 이탈 |
| CH4 | 10~12분 | 편지 정보 구간에서 정체 |
| CH6 북극성 | 12~18분 | 기록/도구/엔딩 단계에서 정체 |

유혹 진입률은 다섯 별문 챕터 × 10런의 `50기회`를 분모로 쓴다.
Route 선택률은 챕터별 10런 × 2개 장착의 `20선택`을 분모로 쓴다.

## 세션 중 확인

- [ ] 세 Route의 차이가 보상 문구가 아니라 행동 방식으로 구분된다.
- [ ] 두 기여 물건을 별문에 직접 장착했다는 사실을 이해한다.
- [ ] GateActive와 동시에 첫 방울을 인지한다.
- [ ] 두 번째 방울 전에는 유혹 탐험을 계속할지 떠날지 고민한다.
- [ ] 냄새를 줄였을 때 다음 방울까지 시간을 벌었다고 느낀다.
- [ ] 이미 울린 방울이 취소되지 않는 규칙을 이해한다.
- [ ] 세 번째 방울과 GateClosing의 인과가 분명하다.
- [ ] 강제 귀가 뒤 사고 보고서에서 어느 방울 단계의 사고인지 설명할 수 있다.
- [ ] 라니의 명령과 마루의 귀환 행동을 서로 다른 원인으로 해석할 수 있다.

## 엔딩 정보량 질문

엔딩 직후 공략 화면을 다시 열기 전에 답을 받는다.

1. 마루가 별길을 없애는 이유는 무엇인가?
2. 라니의 명령이 문제였던 이유는 무엇인가?
3. 플레이어가 마지막에 직접 바꾼 것은 무엇인가?
4. 별길 엔딩이라면 기억·연결·배송·빛 조건을 몇 개나 자기 말로 설명할 수 있는가?
5. 가장 기억에 남은 정보와 불필요하거나 반복된 정보는 무엇인가?

일반 엔딩은 핵심 `3`단위, 별길 엔딩은 추가 조건을 포함한 `7`단위를 기준으로
정답 수와 주관적 과부하를 함께 기록한다.

## 배치 종료

- [ ] 감사 메뉴를 다시 실행해 누적 런 수와 Route 선택률을 보고서에 반영한다.
- [ ] 일반/별길 중앙값과 각 챕터 중앙값을 계산한다.
- [ ] 10% 미만 Route가 있으면 보상 수치보다 발견성·행동 차이부터 수정한다.
- [ ] 유혹 진입률이 낮으면 입구 발견성과 기대 보상을, 높으면 이탈 비용을 점검한다.
- [ ] 시간 목표를 맞추기 위해 반복 이동만 늘리지 않는다.
- [ ] 충돌·진행 불가·상태 단절이 한 번이라도 있으면 밸런스 판정보다 먼저 수정한다.
