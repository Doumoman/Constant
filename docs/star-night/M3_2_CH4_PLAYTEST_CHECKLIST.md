# 《별을 물어오는 밤》 M3-2 CH4 플레이테스트 체크리스트

## 세션 절차

1. `Assets/Scenes/StarNight/StarNight_StarPostOffice.unity`를 연다.
2. 공략 설명 없이 한 번 플레이한다.
3. 선택한 Route 두 개, 봉인 처리, 심층 보관소 진입, 최종 방울 단계를 기록한다.
4. 종료 뒤 Unity Console의 `[M2 Playtest]` 계측 한 줄을 함께 보존한다.

## 종료 질문

1. 현재 목표가 북극성 도장 회수가 아니라 주소 조각 2개였다고 설명할 수 있는가?
2. 정규 우편, 반송 불가 우편, 봉인 편지의 안전·위험·사생활 차이를 구분했는가?
3. 편지를 열지 않고 주소만 복사하는 해법에 정규 분류 지식이 필요하다는 점을 이해했는가?
4. 봉인을 빠르게 사용하면 내용은 읽지 않아도 사생활과 라니 관계에 비용이 생긴다고 느꼈는가?
5. `2/2`와 손잡이 가동이 다른 단계임을 이해했는가?
6. 메인 통신 기록 일부는 필수이고, 전체 맥락은 심층 보관소의 선택 진실이라고 구분했는가?
7. 심층 보관소가 즉시 출항 대신 선택하는 위험한 잔류라고 느꼈는가?
8. 세 번째 방울에서 목적지 우체통까지 이동해 출항이 어려워진 이유를 설명할 수 있는가?

## 기술 확인

- A+B, A+C, B+C 조합이 모두 GateReady에 도달한다.
- Route A/B는 지정된 소포를 지정된 주소에 실제 배송해야 완료된다.
- Route C 주소 복사는 Route A 완료 전에는 차단된다.
- 봉인 복사는 편지 보존 플래그를, 빠른 인장 사용은 봉인 훼손 플래그를 남긴다.
- GateReady에서는 출항과 심층 보관소가 열리지 않는다.
- GateActive 뒤에도 메인 통신 기록을 읽지 않으면 출항할 수 없다.
- 심층 보관소는 GateActive 뒤 입구를 직접 선택해야 열리고, 전체 진실과 희귀 우표는 그 뒤에만 획득된다.
- 미장착 세 번째 주소 조각이 남아 있어도 가동 중 별문 프롬프트가 정확하다.
- Bell 2에서 마루는 플레이어보다 마지막 편지와 빛나는 배송물을 먼저 고른다.
- 출항 기록에 CH4 Route 조합, GateActive, BellPhase와 여행 티켓 도장이 남는다.
