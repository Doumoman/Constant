# 《별을 물어오는 밤》 M3-3 CH3 플레이테스트 체크리스트

## 세션 절차

1. `Assets/Scenes/StarNight/StarNight_CloudWhaleRanch.unity`를 연다.
2. 공략 설명 없이 한 번 플레이한다.
3. 선택한 Route 두 개, 구루 처리, 무지개 목장 진입, 최종 방울 단계를 기록한다.
4. 종료 뒤 Unity Console의 `[M2 Playtest]` 계측 한 줄을 함께 보존한다.

## 종료 질문

1. 현재 목표가 비구름 3개가 아니라 서로 다른 바람 2개였다고 설명할 수 있는가?
2. 목장 수차, 폭풍 능선, 구루 기상의 안전·위험·속도 차이를 구분했는가?
3. 구름병으로 한 대상의 무게를 덜면 반드시 다른 대상에 남겨야 한다고 이해했는가?
4. 구루의 숨결을 얻은 뒤 GateReady 전에 다시 재울 수 있다는 수습 기회를 발견했는가?
5. 구루의 닻을 푸는 선택이 바람 기여와 별개의 사건이라고 이해했는가?
6. 마루가 새끼 고래를 돌려놓은 장면에서 마루의 임무를 어떻게 해석했는가?
7. `2/2`와 손잡이 가동이 다른 단계임을 이해했는가?
8. 무지개 목장이 즉시 출항 대신 선택하는 위험한 잔류라고 느꼈는가?
9. 세 번째 방울에서 풍향이 뒤집혀 출항이 어려워진 이유를 설명할 수 있는가?

## 기술 확인

- A+B, A+C, B+C 조합이 모두 GateReady에 도달한다.
- Route A/B는 비구름의 질량과 수차 도착 조건을 실제로 만족해야 완료된다.
- 구루 방울은 세 번째 상호작용에서만 Route C를 완료한다.
- Route C 수습은 GateReady 전에만 가능하며 폭풍 피해와 구루 상태를 복구한다.
- 구루 닻 해방만으로 GateContribution이 증가하지 않는다.
- 이동식 수차는 구루 해방 뒤 바람 2/2가 준비되어야 완성된다.
- GateReady에서는 출항과 무지개 목장이 열리지 않는다.
- 무지개 목장은 GateActive 뒤에도 입구를 직접 선택해야 통과된다.
- 큰 구름병은 무지개 목장 진입 전에는 획득할 수 없다.
- Bell 2에서 마루는 플레이어보다 공중 물체와 새끼 고래를 먼저 고른다.
- 출항 기록에 CH3 Route 조합, GateActive, BellPhase와 여행 티켓 도장이 남는다.
