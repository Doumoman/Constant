# 《별을 물어오는 밤》 M2 CH1 플레이테스트 체크리스트

대상 씬:
`Assets/Scenes/StarNight/StarNight_MoonMill.unity`

목적:
M1에서 구현한 세 경로·수동 별문·세 번의 방울이 설명 없이도 읽히는지 확인한다.

## 세션 진행

1. 테스터에게 조작만 알려 주고 목표나 정답 경로는 설명하지 않는다.
2. CH1을 처음부터 출항 또는 강제 귀가까지 플레이하게 한다.
3. 플레이 중에는 질문에 답하지 않고 막힌 지점과 발화만 기록한다.
4. 종료 직후 아래 여섯 질문을 순서대로 묻는다.
5. Unity Console의 `[M2 Playtest]` 한 줄을 세션 표에 옮긴다.

## 종료 직후 질문

1. 이 장에서 가장 먼저 해야 했던 일은 무엇이었나?
2. A/B/C 경로는 각각 어떤 위험과 대가가 있었나?
3. 길떡 `2/2`가 되었을 때 왜 바로 출항할 수 없었나?
4. 별문 손잡이를 당기면 무엇이 시작된다고 이해했나?
5. 달 뒤편 창고는 필수였나, 선택이었나?
6. 세 번째 방울에서 붙잡혔다면 실패 원인은 무엇이었나?

정답 판정 기준:

- 목표: 세 경로 중 두 곳의 길떡을 별문에 장착한다.
- 역할: A 안전·협력, B 위험·탐색, C 빠름·차용.
- 준비와 가동: `2/2 GateReady` 뒤 손잡이를 당겨야 GateActive가 된다.
- 추격 시작: 손잡이 가동이 첫 방울과 추격 곡선의 시작이다.
- 유혹: 달 뒤편 창고는 출항을 미루는 선택 구역이다.
- 실패: 세 번째 방울 뒤에는 마루가 물건이 아니라 플레이어를 직접 쫓는다.

## 통과와 중단

- 목표 이해도 80% 이상
- 별문 가동이 추격 시작이라고 답한 비율 60% 이상
- 모든 Route 선택률 10% 이상
- 선택 창고를 강제로 느낀 비율 40% 미만

위 항목 중 두 개 이상 실패하면 CH2 이식을 중단한다.

우선 조정 순서:

1. 목표 오독: 시작 안내와 묘월 첫 대사 수정
2. Route 편중: 거리, 냄새, 보상, 반환 가능 여부 수정
3. 가동 오독: 2/2 토스트와 별문 월드 표지 수정
4. 유혹 강제 인식: 출항문과 선택 창고의 위치·문구 수정
5. Bell 실패 오독: HUD, 환경 흔적, 강제 귀가 설명 수정

## 내부 M2 1차 결과

- A+B, A+C, B+C 모두 GateReady 도달
- A+C 실제 씬 스모크에서 동적 표지 `2/2 → 손잡이 → 방울 1` 전환
- 선택 창고 진입과 Bell 2 뒤 출항 결과가 Telemetry에 기록
- 자동 테스트 시간값은 실제 플레이 속도가 아니므로 이해도·60초 목표 판정에는 사용하지 않는다.
- 실제 사람 5세션 표본을 채우기 전에는 통계형 M2 게이트를 최종 통과로 선언하지 않는다.
