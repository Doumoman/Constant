# 캐릭터 데이터 규칙 v2.0

- 이동·피해·인벤토리 튜닝값의 authoritative source를 하나만 둔다.
- 같은 의미의 값을 코드, Prefab, ScriptableObject, CSV에 중복 소유하지 않는다.
- 테스트는 복제 상수가 아니라 실제 등록 소스를 사용한다.
- 이동 검증 기준은 2셀 높이 도달, 2셀 틈 통과, 3셀 기본 통과 실패다.
- Authoring 설정과 실행 진단 결과를 같은 파일에 기록하지 않는다.
- MAP 좌표와 셀 의미를 캐릭터 쪽에서 재정의하지 않는다.
- 필드 추가·삭제·이름·단위·저장 의미 변경은 CHANGE CONTROL 대상이다.
