# 캐릭터 데이터 규칙

- 이동·피해·인벤토리 튜닝값의 저장 형식은 CHAR00 조사 결과를 따르며 새 형식을 임의 도입하지 않는다.
- 같은 의미의 값을 코드, Prefab, ScriptableObject, CSV에 중복 소유하지 않는다.
- 테스트는 설정값을 복사하지 않고 실제 등록 소스를 사용한다.
- 결과 기반 이동 기준은 2셀 점프, 2셀 달리기 틈, 3셀 기본 통과 불가다.
- 생성되는 진단 결과와 Authoring 설정을 동일 파일에 기록하지 않는다.
- 필드 추가·삭제·단위 변경은 CHANGE CONTROL 대상이다.
