# 캐릭터 잠금 규칙 v2.0

- 실제 지형 단위는 `1 logical cell = 1 world unit`이다.
- 플레이어 기준 CapsuleCollider2D 크기는 `0.72 × 0.90` world unit이다.
- 기본 점프로 높이 2셀 발판에 도달할 수 있어야 한다.
- 동일 높이 2셀 간격은 달리기로 통과할 수 있어야 한다.
- 동일 높이 3셀 간격은 기본 이동만으로 통과할 수 없어야 한다.
- 벽 점프, 대시, 이중 점프를 추가하지 않는다.
- 입력 의미는 Move, Down, Jump=Space 기준, Action=X, Down+X=안전 내려놓기, Bomb=Z, Rope=C다.
- 별도 일반 공격 버튼이나 일반 공격 상태를 추가하지 않는다.
- 전투는 밟기, 접촉, 투척물, 폭탄, 도구, 환경 경로를 사용한다.
- 휴대 슬롯은 하나이며 최초 지원 휴대물 크기는 1×1 이하이다.
- 카메라룸은 연출 단위이며 이동 월드를 분리하지 않는다.
- 방 전환 중 입력과 속도는 KEEP한다.
- 목적지 방이 준비되지 않았으면 경계를 막고 Hysteresis로 반복 전환을 방지한다.
- 캐릭터는 MAP의 공용 좌표·질의·변경 요청 계약만 사용하며 Tilemap 내부를 직접 읽거나 수정하지 않는다.
- 게임플레이 판정은 Animator 이벤트, 렌더 프레임, 사운드 재생 성공 여부에 의존하지 않는다.
- 새 asmdef, 입력 프레임워크, 전역 싱글톤, 공개 API 파괴 변경은 승인된 Task 없이는 도입하지 않는다.
