# 변경 통제 규칙

다음 변경은 현재 TASK에서 임의로 수행할 수 없다.

- 고정 이동 문법 변경
- 기본 공격, 대시, 벽 점프, 이중 점프 추가
- 입력 의미 변경
- 카메라룸 전환 중 입력·속도 KEEP 정책 변경
- MAP 좌표 변환 복제 또는 Tilemap 직접 수정
- 새 asmdef, 전역 싱글톤, 입력 프레임워크 도입
- 기존 공개 API 삭제·이름 변경
- 저장 데이터 의미 또는 단위 변경

변경이 필요하면 별도 패치에 이유, 변경 전후, 영향 TASK, 마이그레이션, 신규 회귀 테스트, 승인자를 기록한다. 승인 전 현재 작업은 BLOCKED다.
