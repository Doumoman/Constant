# 변경 통제 규칙 v2.0

다음은 현재 Task가 명시적으로 승인하지 않으면 변경할 수 없다.

- 2셀 점프·2셀 틈·3셀 실패 이동 문법
- 일반 공격, 벽 점프, 대시, 이중 점프 추가
- X/Down+X/Z/C 입력 의미
- 카메라룸 입력 KEEP·속도 KEEP 정책
- MAP 좌표 복제, Tilemap 직접 접근, 요청 없는 지형 변경
- 새 asmdef, 전역 싱글톤, 입력 프레임워크
- 기존 공개 API 삭제·이름 변경
- 저장 데이터 의미·단위 변경

변경이 필요하면 별도 patch에 변경 전후, 사유, 영향 Task, 마이그레이션, 회귀 테스트를 기록한다. 승인 전 현재 Task는 BLOCKED다.
