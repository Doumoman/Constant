# 캐릭터 입력 규칙

## 확정된 논리 의미

- 방향 입력: 이동, 조준, 행동 방향을 제공한다.
- 행동: `X` 의미를 유지한다.
- 안전 내려놓기: 아래 방향과 행동의 조합이다.
- 폭탄: `Z` 의미를 유지한다.
- 로프: `C` 의미를 유지한다.
- 점프: 독립 논리 명령으로 정의하되 실제 장치 바인딩은 CHAR00 조사 결과를 따른다.

## 처리 원칙

- 장치 입력은 논리 입력 스냅샷으로 변환한 뒤 캐릭터 로직에 전달한다.
- Update에서 수집한 눌림 이벤트가 FixedUpdate 전에 소실되지 않아야 한다.
- 동일 프레임 조합 입력은 TASK에서 잠근 우선순위를 따른다.
- 입력 잠금은 단일 bool이 아니라 사유 집합으로 관리한다.
- 카메라룸 전환만으로 입력을 잠그지 않는다.
