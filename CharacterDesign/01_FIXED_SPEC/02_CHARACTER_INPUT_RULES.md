# 캐릭터 입력 규칙 v2.0

## 고정 논리 입력과 기준 바인딩

| 논리 입력 | 의미 | 키보드 기준 바인딩 |
|---|---|---|
| Move | 수평 이동 축 | 수평 방향 축(좌/우) |
| Down | 하강·조합 축 | 아래 방향 축 |
| Jump | 점프 | `Space` (CHAR00_01 조사 선례로 잠금) |
| Action | 행동(들기/놓기/던지기/상호작용) | `X` |
| Down+Action | 안전 내려놓기 | `아래 + X` 조합 |
| Bomb | 폭탄 | `Z` |
| Rope | 로프 | `C` |

## 자산 상태(고정 기록)

- 레거시 `StarNightControls.inputactions`는 Interact=E, UseBomb=F, UseRope=Q로 위 의미와 불일치한다. 컴파일 제외된 참고 선례이며 활성 자산이 아니다(사본 2개, 서로 다름).
- 위 의미를 만족하는 활성 inputactions 자산은 현재 존재하지 않는다. CHAR00_02는 자산을 만들지 않으며, 자산 생성은 WRITE ALLOWLIST로 승인된 CHAR01 이후 구현 Task에서 수행한다.
- 게임패드 바인딩은 키보드 의미 잠금을 침해하지 않는 범위에서 해당 구현 Task에서 정한다.

## 처리 원칙

- 장치 입력은 논리 입력 스냅샷으로 변환한 뒤 캐릭터 로직에 전달한다.
- Update에서 수집한 눌림 이벤트가 FixedUpdate 소비 전에 소실되지 않아야 한다.
- 동일 프레임 조합 입력은 조합 의미가 단일 의미보다 우선한다(예: Down+Action은 안전 내려놓기이며 단독 Action으로 처리하지 않는다).
- 입력 잠금은 단일 bool이 아니라 사유 집합(lockReasons)으로 관리한다.
- 카메라룸 전환만으로 입력을 잠그지 않는다(전환 중 입력 KEEP).
