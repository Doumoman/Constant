# 캐릭터 상호작용 규칙 v2.0

## 휴대 계약(고정)

- 휴대 슬롯은 정확히 하나다. 슬롯이 차 있으면 새 들기는 거부되고 기존 휴대물이 유지된다.
- 최초 지원 휴대물 크기는 1×1 이하다(달떡, 소포, 돌, 상자, 폭탄, 기절 소형 적).

## 행동 계약(고정)

- 상호작용 후보는 명시적인 질의와 우선순위로 하나만 선택한다.
- Action(X) = 들기/상호작용.
- Down+Action = 발밑의 안전한 위치에 내려놓기(투척 아님).
- Up+Action = 위로 던지기, Left/Right+Action = 해당 방향으로 던지기.
- 안전 내려놓기는 놓을 공간이 없으면 오브젝트를 겹쳐 배치하지 않고 행동을 거부한다(overlap reject). 휴대 상태는 유지된다.

## 구현 원칙

- 휴대와 투척의 충돌 레이어·소유자 충돌 유예는 중앙 정책으로 관리한다.
- 캐릭터는 Carryable 내부 상태를 직접 수정하지 않고 계약 메서드나 요청을 사용한다.
