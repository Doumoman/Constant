# 캐릭터 게임플레이 고정 규칙 v2.0

기준: CHAR00_01 조사(`main @ 24cb1b9`, Unity 6000.3.8f1). CHAR00_02에서 잠금.

## 좌표·크기

- `1 logical cell = 1 world unit`.
- 플레이어 기준 콜라이더는 CapsuleCollider2D `0.72 × 0.90` world unit이며 1×1 지형 셀보다 작게 유지한다.
- 플레이어는 1×1 논리 셀 지형 위를 연속 이동한다. 카메라룸은 연출 단위일 뿐 이동 월드를 분리하지 않는다.

## 이동 문법(결과 기준)

- 기본 점프로 높이 2셀 발판에 도달할 수 있어야 한다.
- 동일 높이 2셀 간격은 달리기로 통과할 수 있어야 한다.
- 동일 높이 3셀 간격은 기본 이동만으로 통과할 수 없어야 하며 로프·갈고리·우산·이동 오브젝트 같은 도구·환경 경로가 필요하다.
- 벽 점프, 대시, 이중 점프를 추가하지 않는다.

## 입력 의미(고정)

- Move=수평 축, Down=하강 축, Jump=Space(키보드 기준선), Action=X, 아래+X=안전 내려놓기, Bomb=Z, Rope=C.
- 레거시 자산(Interact=E, UseBomb=F, UseRope=Q)은 이 의미와 불일치하며 컴파일 제외된 참고 선례일 뿐 활성 자산이 아니다.

## 전투·상호작용

- 별도 일반 공격 버튼이나 일반 공격 상태를 추가하지 않는다.
- 전투 경로는 밟기, 접촉, 투척물, 폭탄, 도구, 환경으로 한정한다.
- 일반 적은 첫 밟기에서 기절하고 두 번째 충격 또는 위험 지형에서 제거되는 계약을 지원한다.
- 휴대 슬롯은 하나이며 최초 지원 휴대물은 1×1 이하다(달떡, 소포, 돌, 상자, 폭탄, 기절 소형 적).
- 안전 내려놓기는 놓을 공간이 없으면 겹쳐 배치하지 않고 거부한다.

## 방 전환·MAP

- 방 전환 중 입력과 속도는 KEEP한다.
- 목적지 지형이 준비되지 않은 경계는 통과할 수 없으며 Hysteresis로 경계 반복 이벤트를 방지한다.
- 캐릭터는 MAP의 공용 좌표 변환·월드 질의·지형 변경 요청 계약만 사용하고 Tilemap·MicroChunk·Room Generator 내부를 직접 소유·수정하지 않는다.

## 실행 원칙

- 게임플레이 판정은 Animator 이벤트, 렌더 프레임, 사운드 재생 성공 여부에 의존하지 않는다.
- 새 asmdef, 새 입력 프레임워크, 새 전역 싱글톤, 공개 API 파괴 변경은 승인된 Task 없이 도입하지 않는다.

변경이 필요하면 현재 Task에서 직접 수정하지 않는다. 변경 사유, 전후, 영향 Task, 회귀 테스트, 승인 상태가 포함된 별도 CHANGE CONTROL 패치를 만든다.
