# 캐릭터 게임플레이 고정 규칙

- 플레이어는 실제 1×1 논리 셀 지형 위를 연속 이동하며 카메라룸은 카메라 연출 단위일 뿐 이동 월드를 분리하지 않는다.
- 기본 점프로 높이 2셀 발판에 도달할 수 있어야 한다.
- 동일 높이의 2셀 간격은 달리기로 통과할 수 있어야 한다.
- 3셀 간격은 기본 이동만으로 통과할 수 없어야 하며 로프·갈고리·우산·이동 오브젝트 같은 보조 수단이 필요하다.
- 벽 점프, 대시, 이중 점프를 추가하지 않는다.
- 별도 일반 공격 버튼이나 일반 공격 상태를 추가하지 않는다.
- 기본 전투는 밟기, 오브젝트 던지기, 폭탄, 도구 및 환경 유도를 사용한다.
- 일반 적은 기본적으로 첫 밟기에서 기절하고 두 번째 충격 또는 위험 지형에서 제거되는 계약을 지원한다.
- 1×1 이하 Carryable, 기절한 소형 적, 폭탄, 달떡, 소포, 돌, 상자를 휴대 계약 대상으로 지원한다.
- X는 행동, 아래+X는 안전 내려놓기, Z는 폭탄, C는 로프라는 고정 의미를 유지한다. 점프의 실제 장치 키는 기존 프로젝트 조사 후 잠근다.
- 카메라룸 전환 중 기본 정책은 입력 KEEP, 속도 KEEP이다.
- 목적지 지형이 준비되지 않은 경계는 통과할 수 없으며 Hysteresis로 경계 반복 이벤트를 방지한다.
- 캐릭터는 MAP 내부 구현이나 Tilemap을 직접 소유·변경하지 않고 공용 좌표 변환·월드 질의·지형 변경 요청 계약을 사용한다.
- 게임플레이 판정은 Animator 이벤트, 렌더 프레임, 사운드 재생 성공 여부에 의존하지 않는다.
- 기존 코드를 조사하기 전 새 asmdef, 새 입력 시스템, 새 전역 싱글톤 또는 대규모 리팩터링을 도입하지 않는다.

변경이 필요하면 현재 TASK에서 직접 수정하지 않는다. 변경 사유, 영향 범위, 회귀 테스트와 승인 상태가 포함된 별도 CHANGE CONTROL 패치를 만든다.
