# 캐릭터 이동 규칙

## 결과 기반 기준

- 기본 점프로 2셀 높이 발판 도달 가능
- 달리기로 동일 높이 2셀 틈 통과 가능
- 기본 이동만으로 3셀 틈 통과 불가
- 벽 점프·대시·이중 점프 금지

## 구현 원칙

- 셀 크기와 좌표 변환을 캐릭터 코드에 중복 정의하지 않는다.
- 튜닝값은 코드에 산재시키지 않고 등록된 설정 소스에서 읽는다.
- 이동 판정은 물리 프레임에서 수행한다.
- 애니메이션 Root Motion으로 gameplay 위치를 결정하지 않는다.
- 프레임레이트별 이동 결과의 허용 오차를 테스트 스펙에 기록한다.
