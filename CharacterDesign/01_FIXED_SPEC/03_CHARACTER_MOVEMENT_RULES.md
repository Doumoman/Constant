# 캐릭터 이동 규칙 v2.0

## 결과 기반 기준(고정)

- 기본 점프로 2셀 높이 발판 도달 가능.
- 달리기로 동일 높이 2셀 틈 통과 가능.
- 기본 이동만으로 동일 높이 3셀 틈 통과 불가 — 도구 또는 환경 경로가 필요하다.
- 벽 점프·대시·이중 점프 금지.
- 수치 튜닝의 PASS 판정은 값 자체가 아니라 위 이동 문법 결과로 한다.

## 물리·접지 기준선(고정)

- Rigidbody2D 호환 모터를 사용하며 수동 중력을 허용한다.
- 접지 판정 = 하향 CapsuleCast + 수직 속도 게이트.
- probe distance 기준선 `0.08`, 접지 수직 속도 임계 기준선 `vy ≤ 0.05`.
- 경사(slope) 정책은 별도 승인 전까지 없음(NONE).
- 좌표 기준 `1 logical cell = 1 world unit`. 셀 크기와 좌표 변환을 캐릭터 코드에 중복 정의하지 않는다.

## 구현 원칙

- 튜닝값은 코드에 산재시키지 않고 등록된 단일 설정 소스에서 읽는다(`03_DATA_SCHEMA/CHARACTER_MOVEMENT_TUNING_SCHEMA.md`).
- 이동 판정은 물리 프레임에서 수행한다.
- 애니메이션 Root Motion으로 gameplay 위치를 결정하지 않는다.
- 프레임레이트별 이동 결과의 허용 오차는 fixture 스펙(`04_TEST_FIXTURES/MOVEMENT_COURSE_SPEC.md`)에 기록한다.
