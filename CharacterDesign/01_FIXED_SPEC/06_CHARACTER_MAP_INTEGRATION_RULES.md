# 캐릭터와 MAP 통합 규칙

- 캐릭터는 MAP의 공용 논리 셀↔월드 좌표 변환 진입점을 사용한다.
- Tilemap, MicroChunk, Room Generator 내부 구현을 캐릭터 런타임에서 직접 참조하지 않는다.
- 지형 파괴는 요청과 결과 계약으로 처리하며 캐릭터가 타일을 직접 삭제하지 않는다.
- 목적지 카메라룸 지형이 준비되지 않았으면 경계 통과를 허용하지 않는다.
- 전환 중 입력과 속도의 기본 정책은 KEEP이다.
- 경계 진입에는 Hysteresis를 적용한다.
- Type1/2/3 필수 경로와 Type0 선택 지역 복귀 가능성을 최종 통합 테스트에서 검증한다.
