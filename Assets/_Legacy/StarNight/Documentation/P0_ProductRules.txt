《별을 물어오는 밤》 P0 제품 규칙
상태: 승인 대기
유일한 제품 기준: 별을_물어오는_밤_신규게임_시스템_GDD_v1.0.md

1. 제품
- 1×1 타일 기반 2D 횡스크롤 플랫폼 로그라이크다.
- PC를 우선하며 키보드·마우스와 게임패드를 동시에 지원한다.
- 플레이어가 배워야 할 필수 목표는 언제나 "출구까지 간다" 하나다.
- 출구는 항상 열려 있고 기본 이동과 점프만으로 도달 가능한 경로가 하나 이상 존재한다.
- 도구, 설화 사건, 기록 길손, 귀향상은 선택 경로와 보상을 만들며 메인 진행을 막지 않는다.
- 영구 능력치 계승은 없다. 엔딩 기록, 도전 과제, 설정, 기록 길손 도감만 영구 저장한다.

2. 월드 규격
- 논리 셀: 1 Unity Unit × 1 Unity Unit.
- 기준 아트: 셀당 48×48px.
- 논리 좌표: 정수 GridPos(x, y).
- 물리: 60Hz Fixed Update.
- 플레이어 기준 크기: 약 0.72×0.90셀.
- 플레이어는 한 셀 높이 통로를 정상 통과해야 한다.
- 연속 이동은 Rigidbody2D, 지형 변화는 정수 셀 요청으로 처리한다.

3. 공정성
- 메인 경로에는 도구 전용 소켓이나 무작위 아이템 조건을 두지 않는다.
- 위험 원인은 화면 안에 있고 치명적 결과에는 최소 한 번의 전조가 있다.
- 낙하·압사·맵 이탈은 즉사가 아니라 체력 1칸과 마지막 안전 셀 복귀로 처리한다.
- 같은 외형, 태그, 도구는 모든 지역에서 같은 의미와 동작을 유지한다.
- 한 방에서 동시에 활성화되는 위험 시스템은 일반 지역 최대 2종이다.

4. 기술 경계
- 저장소: C:/Users/user/Documents/GitHub/Optimal-Selection/Constant
- 신규 구현 루트: Assets/StarNight
- Unity: 6000.3.8f1
- 루트 코드 네임스페이스: StarNight
- 런타임 어셈블리: StarNight.Runtime
- 입력 자산: Assets/StarNight/Input/StarNightControls.inputactions
- 이전 코드·씬·시스템 기획은 수정·마이그레이션·의존 대상이 아니다.
- 기존 디자인과 2D Fantasy Sprite Bundle은 시각 참고 자료로만 사용한다.

5. 입력 계약
- Move: 좌우 이동과 위·아래 방향 의도.
- Jump: 점프.
- Interact: 상호작용·들기·놓기.
- UseHeldTool: 들고 있는 손도구 사용.
- UseRope: 로프 소모품 사용.
- UseBomb: 폭탄 소모품 사용.
- Aim: 갈고리 등 방향 조준.
- Pause: 일시 정지.
