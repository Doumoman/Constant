《별을 물어오는 밤》 폐기 기능 목록
상태: 확정 승인 대기

영구 폐기
- 아이템 합성식, 속성 조합, 세트 효과
- 아이템 등급과 랜덤 옵션
- 여러 칸 인벤토리 퍼즐
- 스탯 중심 빌드
- 영구 능력치 성장
- 메인 출구를 막는 랜덤 아이템 조건
- 보이지 않는 선악·공감 수치
- 설명문을 읽어야만 풀 수 있는 필수 퍼즐
- 화면 밖에서 예고 없이 발생하는 즉사
- 점프 가능성을 검증하지 않는 완전 자유형 절차 타일 생성
- 모든 NPC 구조를 요구하는 진엔딩 체크리스트
- 도구별 강화 트리와 조합식
- 공격 콤보, 스킬 휠, 제작 메뉴

초기 출시 범위 제외
- 상점 절도와 상점주 추격
- 바람 우산의 투사체 반사
- 일반 골드를 귀환결정으로 바꾸는 챌린지 경제

범위 원칙
- 초기 출시 범위 제외 항목은 해당 GDD 단계 이전에 구현하지 않는다.
- 영구 폐기 항목은 플레이테스트 수치 조정으로 되살리지 않는다.
