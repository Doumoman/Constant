# MCP 첫 실행 프롬프트

아래 MCP Starter 규칙을 준수해서 현재 작업을 수행해.

1. `00_MCP_ENTRYPOINT.md`부터 읽고 거기에 지정된 순서대로 전역 규칙을 읽어.
2. `06_IMPLEMENTATION_STATUS.md`의 Current Task만 수행해.
3. 현재 Task의 READ/WRITE ALLOWLIST를 반드시 지켜.
4. 범위 밖 파일을 임의로 수정하거나 다음 Task를 선행 구현하지 마.
5. 현재 Task는 `MAP00_01_PROJECT_AUDIT`이며 읽기 전용 감사다.
6. 프로젝트 구현 파일은 수정하지 말고 `REPORTS/MAP00_01_PROJECT_AUDIT_RESULT.md`만 생성해.
7. 완료 후 `00_MCP_ENTRYPOINT.md`의 종료 보고 형식으로 PASS/FAIL/BLOCKED를 보고해.
8. PASS여도 다음 Task는 자동으로 시작하지 마.
