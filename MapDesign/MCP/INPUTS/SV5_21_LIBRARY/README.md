This package stages one already-registered Task. It authors only a deterministic
20×24 local library shell and future diagonal-stair reservations. It does not
implement stair movement, change Player code, compose the 624×416 world, or use
the retired Sector model.

Verify `FILES.json`, use `STAGE.py --verify-staged`, then perform the native
single-task Apply once. The independent checker validates exported geometry and
