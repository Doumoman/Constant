# SV5 계획 패키지

승인된 624×416 지도 구성에 점프맵 SOLID·Grab·1~2칸 외곽 굴곡 규칙을 추가한 새 작업 목록입니다.

- SPACE_V5_TASKS.md: 순서·Task ID·완료 기준이 있는 45개 작업 목록.
- SPACE_V5_RULES.md: 새 규칙과 유지할 전체 지형 규칙.
- SPACE_V5_MEMORY.md: 다른 대화/MCP로 가져갈 최신 결정 요약.
- TASKS.csv / TASKS.json: 작업 목록의 기계 판독용 사본.
- baseline/: 승인된 정적 예시 셀·장소·연결·검사 결과와 원본 파일 SHA.
- SPACE_V5_RULES.md: 이전 장소·동작·상태 계약. 최신 규칙과 충돌하는 부분은 v5를 우선합니다.

상태는 PLANNED_NOT_INSTALLED입니다. 프로젝트 CURRENT·LOCKED·COMPLETE를 직접 바꾸는 실행 패키지가 아닙니다.
개별 실행 Task는 해당 순서에서 실제 저장소 Read/Write/API·소스 SHA를 바인딩한 뒤 300줄 이하로 발행합니다.
기존 실제 Task·Archive·Result는 보존하고 완료 기능은 현지 증거를 확인하여 재사용합니다.
기존 SV5/19 진행은 별도이며 이번 계획으로 잠금을 해제하지 않습니다.
이번 납품은 작업 목록 작성까지입니다. 점프맵 지형이나 Unity 코드 수정은 아직 수행하지 않았습니다.
