# SPACE v5 최신 결정 메모

- 사용자는 624×416 전체 타일 예시의 구조를 승인했다. 이후 설계의 공간 구성 기준으로 유지한다.
- 여러 마이크로 청크가 하나의 큰 장소를 형성하고, 사이 공간에는 일반 방·굴·샛길·재합류 통로가 촘촘히 연결된다.
- “숨통”은 맵 바깥을 큰 AIR로 비우라는 의미가 아니다. 보상 없는 보통 공간과 다양한 연결도 필요하다.
- 승인 예시의 장소 수·좌표를 모든 시드에 강제하지 않는다. 핵심 진행 ID·보호 셀은 SV5 정본에 연결한다.
- 새 피드백: 점프맵을 ONE_WAY 발판만으로 만들지 말고, 실제 이동에 사용하는 SOLID와 매달릴 수 있는 모서리를 포함한다.
- 새 피드백: 점프맵 내부 외곽이 완전한 사각형처럼 보이지 않도록 일부 경계에 1~2칸의 국소 굴곡을 준다.
- 능력 고정: 일반 +1칸, Jump+Grab으로 최대 +2칸. 고체 아래면 충돌과 당겨 올라서는 공간까지 확인한다.
- 가로 3~4칸 후보는 실제 Player 검증 전 보장하지 않는다. 실패는 지형을 조정하며 능력치를 올려 숨기지 않는다.
- 점프맵 혼합 비율은 미지정. 실제 루트의 Grab 동작 최소 1회와 서로 다른 외곽 구간 2곳은 초기 제작 운영 기준이다.
- 이번 시안 승인과 전 구간 무아이템 완주·기차·엘리베이터·도서관 계단 구현 완료는 별개다.
- 작업 목록은 SV5_01~45로 분리한다. 기존 SV5/19나 완료 Archive·Result를 덮지 않는다.
- 이 패키지는 계획·규칙 문서이며 현재 저장소 상태를 변경하지 않았다.

전달 순서: SPACE_V5_MEMORY → SPACE_V5_RULES → SPACE_V5_TASKS → 해당 작업의 필요한 이전 세부 계약.
MCP에는 작업 하나씩 전달하고 실제 타입/API와 파일 SHA를 확인해 개별 실행 MD를 300줄 이하로 발행한다.
