# SV5_14_JUMP_SOLID package

This package stages the registered SV5_14_JUMP_SOLID Task after the reviewed
SV5_13_JUMP_CONTRACT commit.

SV5_14 builds one bounded 24x32 local jump-room geometry and a real ordered
ascent route that uses both SOLID and ONE_WAY supports. It does not place the
room in the 624x416 world, add Grab movement, deform the room outline, or claim
a live Player completion.

Run STAGE.py --check, --stage, and --verify-staged, then use the repository's
native Apply flow. Read every package file in full.
