# SV5_19_JUMP_RECOVERY package

This package stages the registered SV5_19 Task after accepted SV5_18.

The Task adds a local recovery overlay and one representative miss proof for
each of 18 main links. It does not demand reverse completion, live Player
physics, or any whole-world search.

Run `STAGE.py --check`, `--stage`, and `--verify-staged`, then use the native
repository Apply flow. Do not make ad-hoc CHECK/FILES/VERIFY copies.
