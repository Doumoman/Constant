## 구현

1. 624×416의 평범한 1×1 occupancy dictionary를 baseline layer에서 만든다. 방 AIR/SOLID, host corridor AIR,
   reservation/protected provenance를 합치며 UNKNOWN을 임의 AIR로 간주하지 않는다.
2. supported foot node는 body/head AIR와 아래 SOLID가 있는 좌표다. 이동 edge는 수평 ±1 또는 가로 1을 전제로 한
   높이 ±1만 허용한다. 순수 수직·+2·아이템·외부 AIR 의존은 금지한다.
3. baseline room graph는 실제 Infill parent/link와 host access로 구성하고 component/edge/vertex에서 cycle rank를 계산한다.
   Tarjan 또는 동등한 알고리즘으로 실제 bridge set을 계산한다.
4. loop 후보마다 baseline에서 두 endpoint의 alternate path를 BFS로 찾는다. 없으면 reject한다.
5. 새 loop는 별도 typed topology edge와 ordered tile path를 가진다. host connection에 셀을 합칠 수는 있지만 그것이
   topology proof를 대신하지 못한다.
6. 새 path의 내부는 baseline supported graph와 겹치지 않고 baseline과 정확히 두 endpoint junction에서만 접촉한다.
   새로 AIR로 조각되는 내부 중심선이 최소 2칸 있어야 한다. 중간 교차는 명시한 junction이 아니면 reject한다.
7. 후보 하나를 실제로 추가한 뒤 room graph와 supported cell graph를 다시 계산한다. 해당 edge 제거 시 alternate path가
   남고, 추가 전후 cycle rank delta가 정확히 1이며 실제 bridge set 변화가 계산 결과와 일치해야 한다.
8. baseline shortest cost와 loop 하나를 적용한 final shortest cost를 같은 foot graph·상태·endpoint에서 각각 BFS한다.
   final이 엄격히 작을 때만 RANDOM_SHORTCUT, 아니면 LOOP다. centerline 길이를 baseline cost로 대입하지 않는다.
9. 모든 accepted 후보를 누적한 실제 tile union으로 9 legal FSM states × 6 resource orders를 재검사하고 bypass0을 유지한다.
10. 기존 밀도 계약 default/repeat 각각 accepted>=16, sectors>=12, max length<=24를 유지한다.
11. 동봉 independent checker가 baseline/final cell과 topology edge CSV로 BFS, cycle rank, bridge, 비용을 직접 재계산하게 한다.
12. 개발 중 targeted test를 사용하고 전체 focused 116+신규 회귀는 최종 후보에서 한 번만 실행한다.
