# L03_02 HUD

Short-path MCP package for:

```text
LIVE03_02_IMPLEMENT_HUD_PRESENTATION_AND_RUN_FEEDBACK_BINDING
```

This package opens HUD, presentation event, and run feedback binding for the
live scene.

It must not edit Character runtime, MAP runtime, input assets, tool consumers,
tests, packages, project settings, save data, audio, or animation.

Apply this folder into:

```text
CLI/INBOX/L03_02/
```

Then follow:

```text
CLI/INBOX/L03_02/RUN.md
```
