# L04_01 PlayMode

Short-path MCP package for:

```text
LIVE04_01_CREATE_PLAYMODE_KEYBOARD_AND_GENERATED_RUN_SMOKE
```

This package opens the PlayMode validation task for the live integration
sequence. It creates PlayMode tests only.

It must not edit production runtime, scene, prefab, input assets, Character
runtime, MAP runtime, packages, project settings, save data, audio, or
animation.

Apply this folder into:

```text
CLI/INBOX/L04_01/
```

Then follow:

```text
CLI/INBOX/L04_01/RUN.md
```
