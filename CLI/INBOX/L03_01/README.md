# L03_01 Tools

Short-path MCP package for:

```text
LIVE03_01_IMPLEMENT_CARRY_DROP_THROW_BOMB_ROPE_CONSUMERS
```

This package opens the first LIVE03 implementation task. It implements live
runtime consumers for the existing Character carry, drop, throw, bomb, and rope
request contracts.

It does not wire scenes, prefabs, HUD, audio, save data, animation, or PlayMode
tests.

Apply this folder into:

```text
CLI/INBOX/L03_01/
```

Then follow:

```text
CLI/INBOX/L03_01/RUN.md
```
